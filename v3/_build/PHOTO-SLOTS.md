# Photo slots in the Consultore clone

Every template placeholder is filled today with one of the 8 photos already used on the current site (v3/assets/photos/). To switch to Unsplash or Pexels photos, provide one landscape original of at least 1600 px wide per row of the table, with the photographer name and photo URL for CREDITS.md. The build crops each original to the exact slot sizes below, so a single original can serve several slots. Spanish pages use the same slots.
